# Open Agent Channels

![OAC — Open Agent Channels](https://raw.githubusercontent.com/wiki/RossGraeber/OAC/oac-test-card.svg)

**Messages between live AI harness sessions.**

OAC is a provider-neutral messaging project for existing AI harnesses. Its intended
operation is direct, active delivery and replies between sessions launched OAC-enabled.

**Project phase:** provider and transport spikes, before a released CLI.
The [status ledger](https://github.com/RossGraeber/OAC/blob/main/docs/planning/STATUS.md) is authoritative for stages,
gate verdicts, and unresolved findings.
