## What it shows

- **Registration at start:** the `SessionStart` hook and the shim paired, and each run was one bound session.
- **Deregistration at exit ([SC-ID-155]):** after each run ended, no session was listed.
- **The C4 §6 rule, live:** a resumed or continued Claude session is a new OAC session.
  - At Claude Code `2.1.312`, print mode, runs B (`--resume`) and C (`--continue`) both reported run A's `session_id` in their `--output-format json` results.
  - OAC still gave each run a new session id.
  - This is the case `adapters/claude/tests/registration.rs` `the_hook_session_id_registers_the_session_across_start_resume_and_exit` models with its fake harness: same hook `session_id`, new process, new OAC session.
- The daemon accepted six connections and saw six end: a shim and a hook handler per run (`scenarioData.daemon`).
- **One binding diagnostic, in run C only:** `binding Diagnostic SC-ID-142 Bound attachment=Some(ConnectionHandle(#5)) session=None` (`scenarioData.daemon.bindingLines`; `events-2026-10-31.jsonl` line 22, inside run C's accept-to-end window).
  - SC-ID-142 (`spec/session-channels.md` §6.7.3, case 4) records a binding at a transition while the attachment's or the signal's cross-check value differs from N, the hook's `session_id`. For Claude Code, the cross-check value is `CLAUDE_CODE_SESSION_ID` in the environment of the shim or the hook handler (`adapters/claude/src/hook.rs`).
  - **So under `--continue`, the session id Claude Code put in its subprocesses' environment was not the continued id that the hook reported.** Under `--resume` (run B) the two agreed: no diagnostic.
  - The binding still happened under a new OAC session id, as case 4 requires ([SC-ID-140]). The diagnostic is the record SC-ID-142 asks for, not a failure.
  - `session=None` is expected: the log's `session` field names only a session that was deregistered, withheld or kept (`core/src/session_binding.rs`, `BindingLogEntry::session`).
  - The run cannot tell which of the two connections, the shim's hello or the hook handler's environment, carried the differing value.
