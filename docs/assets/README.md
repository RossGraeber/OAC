# OAC brand assets

The logo evokes a television test card using the shaded block characters `░`, `▒`,
and `▓` (Unicode equivalents of CP437 characters 176, 177, and 178).
The subtitle is **Open Agent Channels**.

- `oac-test-card.svg`: colored character art for README and wiki use.
- `oac-test-card.txt`: plain-text fallback for logs and monochrome displays.
- `oac-test-card.ans`: UTF-8 character art with ANSI true-color sequences for terminals.

Use a monospaced font with block-character support. GitHub Markdown code blocks do
not render ANSI colors; embed the SVG there. Keep the seven top color bars contiguous
and preserve the compact spacing. The original art is provided under the repository's
Apache-2.0 license.

Wiki page sources live in `docs/wiki/`; the GitHub wiki has a separate Git repository.
Keep these sources and published pages in sync when editing the wiki.
